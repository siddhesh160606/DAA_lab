## Problem Description
Implement Quick Sort algorithm to sort movie recommendation data (`movies_sample.csv`) based on user choice:
1. IMDb Rating
2. Release Year
3. Watch Time Popularity

## Files
- `quicksort.cpp`: Source code implementing Quick Sort with multiple partition criteria.
- `movies_sample.csv`: Input dataset containing movie details.
- `output.txt`: Sample execution output showing sorted movies list.

## Compilation & Execution
```bash
g++ quicksort.cpp -o quicksort
./quicksort
```
