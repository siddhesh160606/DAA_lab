## Problem Description
Implement the Fractional Knapsack algorithm using a Greedy approach to maximize total utility value of relief supplies loaded onto a rescue boat given a strict weight capacity.

## Files
- `knapsack.cpp`: Source code implementing Greedy Fractional Knapsack.
- `relief_items.csv`: Input dataset containing relief item weights, utility values, and divisibility status.
- `output.txt`: Sample output of selected relief items and total utility.

## Compilation & Execution
```bash
g++ knapsack.cpp -o knapsack
./knapsack
```
